# Publicacion del repositorio (por realizar desde la cuenta del estudiante)

## Opcion A: desde GitHub y Git
1. Accede a https://github.com/new y crea un repositorio **publico** llamado `taller-apache-camel-tiendasol`. No actives la creacion automatica de README ni .gitignore.
2. Abre una terminal dentro de `Taller_Apache_Camel_TiendaSol`.
3. Ejecuta (reemplaza TU_USUARIO):

```bash
git init
git add .
git commit -m "Implementar taller File Transfer con Apache Camel"
git branch -M main
git remote add origin https://github.com/TU_USUARIO/taller-apache-camel-tiendasol.git
git push -u origin main
```

4. Copia el enlace REAL de GitHub y agregalo a la portada/entrega. No publiques el enlace de ejemplo.

## Opcion B: GitHub Desktop
1. File > Add local repository (o Create a Repository a partir de esta carpeta).
2. Publish repository.
3. Copia la URL de tu repositorio ya creado.

**Nota:** Este paquete no crea por si solo un repositorio publico, ni incluye un enlace inventado.
